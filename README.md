# NSCLC Landmark Trials Database

這是一個個人維護的 NSCLC landmark trials 快速查詢頁，供臨床學習、教學與查房前快速複習使用。

## 使用方式

公開網站只需要 `index.html`。若使用 GitHub Pages，請將本資料夾內容上傳到 repository，並在 GitHub Pages 設定中選擇從 `main` branch 發布。

## 注意事項

- 本資料庫不是正式 guideline。
- 實際治療決策仍需依最新 guideline、藥品仿單、健保規範、院內規範與病人個別狀況判斷。
- 頁面僅保留 PMID，不公開 PDF。
